Read that second row as the honest summary of this system. The agent remembers one conversation, well. It does not get better at anything. 3 · Why "blackboard" is the right word

Careful, because this page is a whiteboard and the word means something else entirely. The blackboard architecture is the oldest shape in the field — Lenat's DENDRAL, 1970s: a shared board where specialists independently read from and write to a common knowledge base, with no expert talking directly to another. CoALA is that pattern with the regions named. Nothing to do with the colour of this page.

CLASSIC BLACKBOARDCOALAOURS
The shared blackboard Working memory WorkingMemory.compose() · memory.py:423
Knowledge sources Episodic + semantic The two read paths
Specialists Internal actions reasoning, retrieval — no learning
The scheduler The decision process The model, at cognition.py:821
The difference that matters. In DENDRAL the specialists were different programs — a parser and a planner knew different things. In ours there is one specialist: the model. The four regions still exist, but only procedural memory has a genuinely non-model author. That is why the action space has to be written by hand, and why the memory's write path is a no-op: with a single author, everything the agent "learned" would be the model rewriting its own instructions.
